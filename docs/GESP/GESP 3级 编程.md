## 桶排序 / 计数思想（常考第一题）

用**数组下标当“桶”**：要么统计出现次数，要么标记“有没有出现过”，要么按桶累加。

- **春游**：同学编号 0～N-1，报出的编号可能有重复，求**没到的人**。开一个 `bool came[N]` 或 `int cnt[N]`，把报出的编号对应位置设为 true 或 cnt++，最后看哪些没出现。
- **小杨的储蓄**：第 $i$ 天往存钱罐 $a_i$ 里存 $i$ 元。开 `long long bucket[N]`，读入 $a_i$ 后做 `bucket[a_i] += i` 即可。
- **字母求和**：小写 a→1、b→2…，大写用 ASCII 的相反数。遍历字符串，按 `islower/isupper` 分支，累加进一个 `sum`。
- **数字替换**：先扫一遍求序列的 min 和 max，再扫一遍：大于 k 的变成 max，小于 k 的变成 min。

```c++
// 春游：标记谁到了，最后输出没到的
bool came[1005];
int n, m, id;
cin >> n >> m;
for (int i = 0; i < m; i++) {
    cin >> id;
    came[id] = true;
}
for (int i = 0; i < n; i++)
    if (!came[i]) cout << i << " ";
```

## 字符串（常考第二题）

考点：**读入整行或带空格的串**、**按字符遍历**、**解析固定格式**、**大小写/字符类型判断**。

- **单位转换**：读入如 `1 km = ? mm`，用 string 或 getline，找空格和关键字确定单位和倍数，换算后按格式输出。
- **词频统计**：单词统一 tolower，用 `map<string,int>` 或数组（若只含小写）计数，再找出现次数最多的。
- **进制判断**：看字符串里有没有超过 0–1 / 0–7 / 0–9 / 0–9 与 A–F 的字符，决定 2/8/10/16 是否可能。
- **密码合规**：长度 6–12，只能含大小写、数字、!@#$；且“大小写+数字”至少两种、特殊字符至少一个。设几个 bool（有大小写、有数字、有特殊字符），遍历一遍判断。
- **移位**：大写字母循环右移 n 位，`(ch - 'A' + n) % 26 + 'A'`，逐字符输出。

```c++
// 词频统计：忽略大小写，找出现最多的单词
map<string, int> cnt;
string s;
for (int i = 0; i < n; i++) {
    cin >> s;
    for (char& c : s) c = tolower(c);
    cnt[s]++;
}
// 再遍历 cnt 找 max 对应的单词
```

## 数组与序列

3 级里还有不少题以**数组、序列**为主：前缀和、最值、按规则模拟等。

### 前缀和与平衡点

典型题：[GESP202409 三级] 平衡序列。判断是否存在位置 $i$，使得前 $i$ 个元素之和等于后面元素之和。

思路：先求整个序列的和 $sum$，再从左到右扫一遍，维护前缀和 $pre$，若某一位置有 $pre = sum - pre$（即前一半和等于后一半和），则存在平衡点。

```c++
// 核心思路：前缀和
long long sum = 0;
for (int i = 0; i < n; i++) sum += a[i];
long long pre = 0;
for (int i = 0; i < n - 1; i++) {
    pre += a[i];
    if (pre == sum - pre) { /* Yes */ break; }
}
```

### 序列最值与替换

[GESP202412 三级] 数字替换：大于 $k$ 的换成序列最大值，小于 $k$ 的换成序列最小值。先遍历一遍求 $\min$ 和 $\max$，再遍历输出即可。

### 按规则模拟到全 0

[GESP202509 三级] 数组清零：每次选**下标最大的**最大值，减去**当前非零中的最小值**，直到全 0。直接按题意模拟，注意“多个最大值取下标最大”“非零中的最小”即可。

## 字符串与映射

### 解析与单位转换

[GESP202312 三级] 单位转换：输入形如 `1 km = ? mm`，解析出数字和单位，按长度/重量的进制换算后输出。可用 `string` 读入，找空格和关键字确定单位和倍数（如 km→mm 乘 1000000）。

### 词频统计（忽略大小写）

[GESP202503 三级] 词频统计：统计出现次数最多的单词，大小写视为同一单词。做法：把每个单词统一转为小写（或大写），用 `map<string, int>` 计数，再找出现次数最多的那个。

```c++
map<string, int> cnt;
string s;
while (n--) {
    cin >> s;
    for (char& c : s) c = tolower(c);
    cnt[s]++;
}
// 再遍历 cnt 找 max
```

### 进制与字符规则

[GESP202309 三级] 进制判断：根据字符集合判断可能是 2/8/10/16 进制（二进制只能 0、1，十六进制可含 A–F 等）。  
[GESP202406 三级] 移位：大写字母表循环右移 $n$ 位，即 Caesar 密码，`(ch - 'A' + n) % 26 + 'A'`。

### 密码合规

[GESP202306 三级] 密码合规：长度 6–12，只能含大小写字母、数字和 !@#$，且“大小写+数字”至少两种、特殊字符至少一个。按条件分支判断即可。

## 位运算与数学性质

### 二进制 1 的个数与奇偶

[GESP202506 三级] 奇偶校验：求若干整数在二进制下 1 的总个数，以及总个数的奇偶性（校验码）。统计每个数二进制 1 的个数再相加即可。

```c++
int count_one(int x) {
    int c = 0;
    while (x) { c += x & 1; x >>= 1; }
    return c;
}
```

### 按位与、或与方程

[GESP202503 三级] 2025：求最小正整数 $y$ 使得 $(x \operatorname{and} y) + (x \operatorname{or} y) = 2025$。利用恒等式 $a + b = (a \operatorname{and} b) + (a \operatorname{or} b)$，可知 $x \operatorname{or} y = 2025 - (x \operatorname{and} y)$，再结合位运算约束枚举或推导 $y$。

### 完全平方与倍数

[GESP202403 三级] 完全平方数：序列中有多少对 $(i,j)$ 满足 $A_i+A_j$ 为完全平方数，可枚举 pairs 或枚举和再检查是否为平方数。  
[GESP202406 三级] 寻找倍数：是否存在某个 $a_i$ 是序列中所有数的倍数，即 $a_i$ 等于全序列的 $\gcd$ 的某个倍数，等价于该数是序列最大值且能整除所有数（或先求全局 $\gcd$ 再看是否存在 $a_i = \gcd$）。

## 模拟与格式输出

### 固定模板输出

[GESP202412 三级] 打印数字：把 0、1、2、3 用给定的 5×5 字符图案输出，多位数则横向拼接。用二维字符数组存每个数字的图案，按位取图案按列输出即可。

### 日历

[GESP202509 三级] 日历制作：输出 2025 年某月的日历，第一行 MON TUE … SUN，下面日期按星期对齐。先算该月 1 号是星期几（可手算或简单日期逻辑），再按 7 列输出，注意个位与对应星期缩写最后一个字母对齐。

## 其他经典题简述

- **小猫分鱼** [GESP202312 三级]：整除链 + 数学构造，从最后一只猫倒推初始鱼数。  
- **分糖果** [GESP202506 三级]：每人至少 $a_i$ 且严格递增，贪心让每人取“上一个人+1”和 $a_i$ 的较大值，再求和。  
- **小杨的储蓄** [GESP202309 三级]：按天往不同桶里加钱，用数组累加即可。  
- **春游** [GESP202306 三级]：报编号，求未到的同学，用布尔数组或计数标记是否出现过。  
- **字母求和** [GESP202403 三级]：小写 a→1, b→2…，大写用 ASCII 的相反数，遍历求和。

3 级相对 2 级，从“数位+简单循环”升级为以**数组、字符串、位运算与规则模拟**为主，做题时注意数据类型（如 `long long`）、边界和格式输出的空格与换行。
