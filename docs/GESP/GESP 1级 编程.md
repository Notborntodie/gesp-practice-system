## 数学应用计算题

如果看到**题目描述**或者**输入/输出**出现小数，一定要记得使用`double`  类型

* 经典题目：[GESP202509 一级] 商店折扣 / [GESP202412 一级] 温度转换

同时一般配合考察的是，格式化输出的方法

```c
printf("%.2lf",a);
```

`a`是变量名，`%lf`s是输出`double`类型的占位符，`.2`表示保留2位小数（当然保留几位取决于题目要求）。



⚠️我们同学们很容易忘记的是**如何格式化输出多个变量**。这点在 [GESP202412 一级] 温度转换这道题有所体现（如下）

##  进位运算





求余运算 % 和整除运算 / 的配合使用在 **进位计算**中，

我们同学都知道可以通过求余10获得末位，再使用整除10去除末位，比如

```c++
a=156;
b=a%10; // 获得156的末位
a=a/10; // a去除末位变成15
```

这其实可以被使用在进位计算中

如  [GESP202406 一级] 休息时间 ，

<img src="/Users/zhengyanchen/Library/Application Support/typora-user-images/截屏2026-02-26 11.44.02.png" alt="截屏2026-02-26 11.44.02" style="zoom:33%;" />

```c++
s+=k; //秒加上 k 秒
m+=(s/60); 
s=s%60
```

只不过秒如果要进位，需要整除60，而不是10了。这是因为一分钟有60秒。

### flag小旗子



flag 往往是用来**判断for循环中，是否找到满足条件的值**

我们以 [GESP202406 一级] 立方数 为例子

<img src="/Users/zhengyanchen/Library/Application Support/typora-user-images/截屏2026-02-26 13.55.55.png" alt="截屏2026-02-26 13.55.55" style="zoom:25%;" />

我们需要判断n是否是立法数，本质是判断，是否能在 1-n的范围内查找到是否存在一个i,能满足 `i*i*i==n`

这道题需要使用flag

```c++
int flag=0;
for(int i=1;i<=n;i++){
  if(i*i*i==n){
    flag=1;
    break;
  }
}
if (flag){
  cout<<"Yes"
}else{
  cout<<"No";
}
```



这基本是写flag的模版，如果找到了一个i,能满足 `i*i*i==n`, flag被修改成1。

⚠️**判断flag的部分, 是写在循环外的**，因为循环是查找。只有查找结束了，我们才会去判断flag小旗子

 ```c++
 if (flag){
   cout<<"Yes"
 }else{
   cout<<"No";
 }
 ```
